# DruMuster

スマートフォン／PC向けのブラウザ・ドラム音楽ゲーム試作版です。

## テスト曲

- なないろ / BUMP OF CHICKEN
- MIDI譜面から4レーンを生成
- ボーカル、ガイドドラムのON/OFF
- オートプレイ（スコア・ベストスコア対象外）
- テンポ80〜120%（5%刻み）
- オフボーカル／ボーカル／ガイドドラム：WAV（44.1kHz / 16bit / stereo）
- ゲーム内ドラム音量：バスドラム140%、クラッシュシンバル120%、その他100%

## PCキー

- 左シンバル `Q` / 右シンバル `P`
- ハイタム `W` / ミドルタム `E`
- ハイハット `A` / スネア `S`
- 特殊打楽器 `D` / フロアタム `K` / ライド `L`
