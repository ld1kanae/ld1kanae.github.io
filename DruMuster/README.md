# DruMuster

スマートフォン／PC向けのブラウザ・ドラム音楽ゲーム試作版です。

## テスト曲

- なないろ / BUMP OF CHICKEN
- MIDI譜面から4レーンを生成
- ボーカル、ガイドドラムのON/OFF
- オートプレイ（スコア・ベストスコア対象外）
- テンポ80〜120%（5%刻み）
- スマートフォン版は端末の画面回転を待たず、最初から横長の固定プレイ画面として描画
- オフボーカル／ボーカル／ガイドドラム：WAV（44.1kHz / 16bit / stereo、サイズ・WAVヘッダー・SHA-256検証付き）
- ゲーム内ドラム：配信用チャンクから単一の `drumsound.wav` をメモリ上で復元し、`drumsound.mid` から求めた音色別の再生位置を使用
- 各ドラム音はBPM 60で収録された2秒の録音区間末尾まで独立再生し、オープンハイハットだけをクローズ／ペダルハイハット発音時にチョーク
- 音源に不足・破損がある場合は代替ノイズを鳴らさず、プレイ開始前にエラー停止
- ゲーム内ドラム音量：バスドラム140%、クラッシュシンバル120%、その他100%
- 全音声をマスターリミッターへ通し、重なった際の爆音・クリッピングを抑制

## PCキー

- 左シンバル `Q` / 右シンバル `P`
- ハイタム `W` / ミドルタム `E`
- ハイハット `A` / スネア `S`
- 特殊打楽器 `D` / フロアタム `K` / ライド `L`
