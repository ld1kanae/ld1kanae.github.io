# DruMuster

スマートフォン／PC向けのブラウザ・ドラム音楽ゲーム試作版です。

## テスト曲

- なないろ / BUMP OF CHICKEN
- MIDI譜面から4レーンを生成
- ボーカル、ガイドドラムのON/OFF
- オートプレイ（スコア・ベストスコア対象外）
- テンポ80〜120%（5%刻み）
- スマートフォン版は端末の画面回転を待たず、最初から横長の固定プレイ画面として描画
- オフボーカル／ボーカル／ガイドドラム：提出済みMP3を直接読み込み、サイズ・SHA-256を検証してから再生
- ゲーム内ドラム：配信用チャンクから提出済み `drumsound2.wav` をバイト単位で復元し、提出済み `drumsound2.mid` のBPM 60・2秒間隔の発音位置を使用
- 各パーツは1つの基準音色だけを使用し、譜面上の別GMノート番号では音色を切り替えず、velocityを音量倍率として反映
- キック=36、スネア=38、フロアタム=41、ミドルタム=45、ハイタム=48、HH Closed=42、HH Pedal=44、HH Open=46、Ride=51、Crash=49、特殊打楽器=37を基準サンプルとして使用
- 各ドラム音は2秒の録音区間末尾まで独立再生し、オープンハイハットだけをクローズ／ペダルハイハット発音時にチョーク
- 音源に不足・破損がある場合は代替ノイズを鳴らさず、プレイ開始前にエラー停止
- ゲーム内ドラム音量：バスドラム140%、クラッシュシンバル120%、その他100%
- 全音声をマスターリミッターへ通し、重なった際の爆音・クリッピングを抑制

## PCキー

- 左シンバル `Q` / 右シンバル `P`
- ハイタム `W` / ミドルタム `E`
- ハイハット `A` / スネア `S`
- 特殊打楽器 `D` / フロアタム `K` / ライド `L`
