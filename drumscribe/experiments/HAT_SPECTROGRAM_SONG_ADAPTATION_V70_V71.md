# Open ハイハット新規打点の追加実験（v70 / v71）

実施日: 2026-09-23（UTC）
状態: **研究結果のみ。採譜本体は変更しない。**

## 入力と評価

`DruMaster/songs/` の5曲の `drums.mp3` から v69 の高域フラックス規則で新規打点候補を作り、先行 v67 の音声予測イベントに Open を追加した。各周回で学習対象から1曲を除外した。除外曲の `chart.mid` は正解ラベルと採点にのみ使用し、候補・予測時の特徴には含めない。±80 ms 一対一で採点し、アルクアラウンドの参照 Ride に重なる HH 予測は既定どおり評価から除外した。5曲合算の HH Open/Closed macro F1 を比較する。各曲の TP / 予測数 / 参照数と全閾値は同名の `results-*.json` に保存した。

5曲は以前から開発に使われている。ここでの曲単位除外は、今回の学習器への同一曲ラベル混入を避けるものだが、独立した未知曲の確認にはならない。以前のブラウザ予測イベントを再利用したオフライン評価であり、今回 fresh Chromium は実行していない。

## v70: 短時間スペクトログラムの分類

候補時刻の前120 msから後520 msまでの16点で、120 Hz～10.5 kHzを24帯域に要約した。曲内候補の中央値でスペクトルを中心化し、アタック・減衰などの既存特徴も入力した。4曲で学習し、残り1曲に Logistic と小型 MLP（隠れ48ユニット）を適用した。陽性の少ない曲が学習を支配しないよう曲別の重みを抑制した。

| 条件 | 報告した閾値のうち最大の合算 F1 | 閾値 | 追加音 / 追加Open正解 |
|---|---:|---:|---:|
| 現行候補 | **0.738864** | — | 0 / 0 |
| 既存特徴 Logistic | 0.737697 | 0.98 | 11 / 1 |
| スペクトログラム Logistic | 0.736083 | 0.98 | 67 / 11 |
| スペクトログラム MLP | 0.736605 | 0.98 | 55 / 9 |

0.60 / 0.70 / 0.80 / 0.90 / 0.95 / 0.98 をすべて報告した。MLP は設定した65回で収束警告が出たため、学習の探索結果として扱う。最良の報告値でも現行を下回り、採用しない。

## v71: 同一曲の既存 Hat/Open 予測を疑似教師にする

除外曲の既存 `hat` / `open_hat` 予測から音響特徴14個を取り、曲内で Logistic を学習した。これは正解MIDIを曲内適応に渡さない方法だが、既存予測の誤りを教師として再学習する。4曲の正解から学習した Logistic、両者の平均、両者の小さい確率を取る合意判定とも比較した。0.50 / 0.70 / 0.85 / 0.95 / 0.98 の全閾値を記録した。

| 条件 | 報告した閾値のうち最大の合算 F1 | 閾値 | 追加音 / 追加Open正解 |
|---|---:|---:|---:|
| 現行候補 | **0.738864** | — | 0 / 0 |
| 曲内疑似教師のみ | 0.692842 | 0.98 | 502 / 38 |
| 4曲教師のみ | 0.740269 | 0.95 | 36 / 14 |
| 平均 | 0.738891 | 0.98 | 3 / 1 |
| 合意 | 0.738891 | 0.95 | 3 / 1 |

4曲教師のみの 0.95 では、曲別 macro F1 の変化はアルクアラウンド **−0.00162**、ダイヤモンドヴァージン **±0**、怪獣 **+0.03810**、なないろ **±0**、Ray **+0.00037**。アルクアラウンドに2件の偽追加がある。閾値を5曲の評価結果から比較しているので、この +0.001406 は探索上の数値であり、独立した汎化改善ではない。既定の曲別非退行条件も満たさず、本番モデル・処理は変更しない。疑似教師は特に偽陽性を増やした。

## 次の判定材料

最大の残存問題は候補到達率よりも追加候補の Precision と曲間の録音差である。さらに同じ5曲で閾値を調整せず、未使用の楽曲と録音キットを確保してから曲／キット単位で事前固定した閾値を評価する。E-GMD の音声を教師に加えるならライセンスと対応 MIDI を確認し、キットと演奏系列をまたぐ分割で評価する。`arrangement/` の反復情報は音源と反復精度の条件が揃った曲にだけ別枠で測定する。改善案ができたら、fresh Chromium の5曲採譜、Kick/Snare/Tom列の一致、曲別 HH 非退行を確認してから統合する。

再現（Python `numpy scipy scikit-learn mido`、`ffmpeg` が必要）:

```bash
python drumscribe/experiments/train_hat_spectrogram_v70.py
python drumscribe/experiments/train_hat_song_adaptation_v71.py
```

生の提供音源・MIDIや音声をリポジトリへ追加しない。
