# 使える日本語を勝手に浴びる

慣用句と用例を眺め、「知ってる」「知らない」「興味ない」とお気に入りの★で整理する、ブラウザ完結型のWebアプリです。

## 語彙の追加

`data/vocabulary_001.txt`、`data/vocabulary_002.txt`……のように、3桁の連番で追加します。番号を飛ばさないでください。アプリは最初に存在しない番号を見つけた時点で読み込みを終了します。

各ファイルはUTF-8のJSON配列です。拡張子だけ `.txt` にしています。

```json
[
  {
    "id": "jp-000001",
    "phrase": "胸を衝く",
    "reading": "むねをつく",
    "meaning": "強い感動や衝撃が、突然心に迫る。",
    "example": "思いがけない手紙の一文が胸を衝いた。",
    "category": "感情・心理",
    "genres": ["喜び・安堵"],
    "similar": ["胸を打つ", "胸に迫る", "心を動かす"]
  }
]
```

- `id` は全ファイルを通じて一意にし、後から変更しません。
- `phrase`、`reading`、`meaning`、`example` は必須です。
- `genres` はジャンル画面に表示する分類名の配列です。複数指定できます。
- `similar` はカードの「近い表現」に並べる表現の配列です。
- 1ファイル100件程度を目安にします。
- 語彙ファイルを並べ替えても、`id` が同じなら利用者の分類状態は維持されます。

## 保存

分類、★、表示設定、途中位置は普段はブラウザの `localStorage` に保存されます。ホームの「データをバックアップ」から、共通セーブデータ `japanese/save_data.json` へ手動で保存・読み込みできます。

GitHubへ保存する端末では、対象リポジトリだけを選択し、Contentsを「Read and write」にしたFine-grained personal access tokenを初回に設定します。トークンはその端末の `localStorage` にだけ保存し、`save_data.json` やローカル書き出しデータには含めません。GitHubからの読み込みにはトークンは不要です。
