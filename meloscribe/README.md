# MeloScribe

ボーカルの単音メロディをブラウザ内で検出し、伴奏から推定した拍にクオンタイズしてMIDIに書き出す試作です。静的ファイルだけで動作し、音声のアップロードやサーバー側の推論は行いません。

## 使い方

```sh
python3 -m http.server 8000
```

`http://localhost:8000/` を開き、ボーカルと、可能ならインストを読み込んで「採譜を開始」を押します。原曲は試聴に利用できます。ボーカルの代わりに、時間軸と音量が揃った「原曲＋インスト」を渡すと差分をボーカルとして利用します。これは厳密に対応したステムだけに有効で、未知の曲を自動分離する機能ではありません。

自動検出の後、BPM、拍位置、クオンタイズ幅を確認します。「元の検出結果から再配置」は現在の手編集を上書きします。音符はクリックで追加、ドラッグで移動・伸縮、Shift＋クリックか右クリックで削除できます。完了したらMIDIをダウンロードします。MIDIはメロディをチャンネル1、PPQ 480、4/4で出力します。

## アルゴリズム

1. インストを11,025 Hzへ変換し、短時間スペクトルの低・中域の正の変化を抽出します。onsetの拍周期の位相集中度を60–220 BPMで探索し、拍の位相も推定します。半拍・倍拍は手動修正が可能です。
2. ボーカルを20 ms間隔で解析し、YINの累積平均正規化差分を自己相関で計算します。音量と周期性が足りない区間を無音扱いにします。
3. 数フレームの欠落と音高の揺れを平滑化し、音高が続く区間を候補音符にします。音符の開始と終了を、拍位相を基準に8分・16分・32分・3連符へクオンタイズします。
4. ピアノロールで音高、開始、長さを修正し、Standard MIDI Fileを書き出します。

拍推定は [DrumScribe](https://github.com/ld1kanae/ld1kanae.github.io/tree/main/drumscribe) の低・中域オンセットと位相集中度の設計を参考にした独立実装です。`drumscribe` のドラム専用モデルやMIDIモジュールをコピーしていません。音高推定は [YINの論文](https://iro.umontreal.ca/~pift6080/H09/documents/papers/yin_pitch_tracker.pdf) に基づきます。

## 添付音源での確認

「八月の蝶 edit2」の3本のWAVは44.1 kHz、stereo、209.143秒でした。原曲と `inst + vocal` のRMS残差は約3.05×10⁻⁵（16-bit PCM量子化の1段階程度）です。インストからのBPM推定は **140.02 BPM**、周期性指標は **0.402**、拍位相は **約0.021秒**。ボーカルからの周期性を満たすフレームは **6,213 / 10,481**、試作の音符候補は **489件**でした。これは正解MIDIと照合した精度の値ではありません。オクターブ誤り、声の重なり、ビブラート、子音、リバーブや伴奏の回り込みによる誤りは手編集が必要です。

## 開発と検証

依存パッケージはありません。`npm test` でFFTの往復、既知の2音の音高、音符の拍グリッドとMIDIヘッダーを検査します。音源をリポジトリへ含めません。
