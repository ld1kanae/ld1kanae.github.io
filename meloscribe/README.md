# MeloScribe

ボーカルの単音メロディをブラウザ内で検出し、伴奏から推定した拍にクオンタイズしてMIDIに書き出す試作です。静的ファイルだけで動作し、音声のアップロードやサーバー側の推論は行いません。音符の開始はボーカルのスペクトル変化から推定し、その後の安定した音高を割り当てます。

## 使い方

```sh
python3 -m http.server 8000
```

`http://localhost:8000/` を開き、ボーカルと、可能ならインストを読み込んで「採譜を開始」を押します。原曲は試聴に利用できます。ボーカルの代わりに、時間軸と音量が揃った「原曲＋インスト」を渡すと差分をボーカルとして利用します。これは厳密に対応したステムだけに有効で、未知の曲を自動分離する機能ではありません。

自動検出の後、BPM、拍位置、クオンタイズ幅を確認します。「元の検出結果から再配置」は現在の手編集を上書きします。音符はクリックで追加、ドラッグで移動・伸縮、Shift＋クリックか右クリックで削除できます。完了したらMIDIをダウンロードします。MIDIはメロディをチャンネル1、PPQ 480、4/4で出力します。

## アルゴリズム

1. インストを11,025 Hzへ変換し、短時間スペクトルの低・中域の正の変化を抽出します。onsetの拍周期の位相集中度を60–220 BPMで探索し、拍の位相も推定します。半拍・倍拍は手動修正が可能です。
2. ボーカルの帯域別スペクトルの正の変化から発音候補を検出します。別に20 ms間隔でYINの累積平均正規化差分を自己相関で計算し、周期性のない区間を除きます。
3. 各発音候補の後の音高を調べ、持続と次の発音で音符を区切ります。同音の発音し直しも別の音符にできます。拍位相を基準に8分・16分・32分・3連符へクオンタイズします。
4. 音高分布からキー候補を表示します。臨時記号や転調を誤って消さないため、推定キーで音高を強制修正しません。ピアノロールで音高、開始、長さを修正し、Standard MIDI Fileを書き出します。

拍推定は [DrumScribe](https://github.com/ld1kanae/ld1kanae.github.io/tree/main/drumscribe) の低・中域オンセットと位相集中度の設計を参考にした独立実装です。`drumscribe` のドラム専用モデルやMIDIモジュールをコピーしていません。音高推定は [YINの論文](https://iro.umontreal.ca/~pift6080/H09/documents/papers/yin_pitch_tracker.pdf) に基づきます。

## 添付音源での確認

「八月の蝶 edit2」の3本のWAVは44.1 kHz、stereo、209.143秒でした。原曲と `inst + vocal` のRMS残差は約3.05×10⁻⁵（16-bit PCM量子化の1段階程度）です。インストからのBPM推定は **140.02 BPM**、周期性指標は **0.402**、拍位相は **約0.021秒**。公開ブラウザ版では発音検出後の16分クオンタイズ結果が **539音符**でした。別の高品質リサンプリングを使ったローカル比較では、音高変化を境界にした旧方式489件、発音検出を使う現方式533件の生候補（クオンタイズ後532件）でした。その比較で16分グリッドまでの開始位置の中央値は旧方式29 ms、現方式19 msです。ブラウザとローカルの音声変換方法が違うため件数は一致しません。

Spotify Basic Pitchの強い出力701件と、同じ音高（±1半音）・開始時刻（±60 ms）で1対1照合した一致数は旧方式315件、現方式405件でした。**Basic Pitchも正解譜ではありません**。これは二つの検出器の一致度であり、実際の正確さを示す値ではありません。音高分布ではD major / B minorが候補ですが、調性は確定していません。オクターブ誤り、声の重なり、ビブラート、子音、リバーブや伴奏の回り込みによる誤りは手編集が必要です。

## 開発と検証

依存パッケージはありません。`npm test` でFFTの往復、既知の2音の音高、同音の再発音、音符の拍グリッドとMIDIヘッダーを検査します。音源をリポジトリへ含めません。
