DruMaster RESULT LAYOUT EDITOR

LAYOUT CONTROLS

ELEMENT

NORMAL RESULTはPC/スマホとも左半分＝結果、右半分＝RANKINGとして25% / 75%位置にセンターガイドを表示します。

SELECTED

Shift＋ドラッグで水平または垂直に固定。Ctrl/Cmd＋クリックで複数選択。複数選択時のX/Yは移動量（ΔX/ΔY）、その他の値は選択要素へ一括適用します。

SAVE / EXPORT

VIEWER URLにはスマホNORMAL/AUTOの現在値を埋め込みます。スマホ側で同じlocalStorageを共有する必要はありません。
