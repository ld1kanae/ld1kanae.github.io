01 / INNER GLOW — WIDTH × NON-LINEAR FALLOFF

一般的なグロー同様、近距離の強いコア・圧縮した中間光・薄い長い尾を重ねた構成です。幅も以前の案に近い領域まで戻しています。すべてゲーム内の結果ボタンと同じ140px幅で表示しています。

A16px / CORE狭め。コア強め＋尾は70%まで
B20px / BALANCEDやや狭め。自然な三段減衰
C24px / COMPRESSED中間を下げ、薄い尾を長めに残す
D28px / WIDE以前に近い幅。中央は低濃度を維持
E30px / CRUSHED MID幅広＋中間調を強く下げた案
F26px / SOFT中間を少し残す一般的な柔らかいグロー
02 / AIRY DROP-GLOW — VERTICAL POSITION

前回のAiryの広がり・濃度・blurは維持し、Y位置だけ上げています。左から旧位置に近い +5px → +3px → +1px → −1px → −3px です。内周はCで固定。

1Y +5px旧Airyに最も近い
2Y +3px2px上
